[03]
How it works

One no, and nothing moves.

  1. 01

    The agent asks to pay

    Payee, amount and a one-line reason. That's all it gets to say.

  2. 02

    Each fuse checks it on X Layer

    Every fuse is a circuit of 11 to 108 logic gates, taped out on TapeOut. All of them run in the same call, and each answers yes or no.

  3. 03

    One no stops the payment

    The wallet records which fuse said no and why. A blown Breaker stays blown until you reset it.

  4. 04

    The designers are paid

    Each fuse that decided earns its fee in USDT0, the no's included.

For agent builders

One call before every payment.

  • The agent's key can only move money through the fuses.
  • Dry-run any payment with check() and see which fuse would blow.
  • Freeze from the agent, an approver or you. Only you can reset.
  • Works with any agent that can sign an X Layer transaction.
agent.tsFuseboxWallet.solMCP
// the agent's key can only pay through the fuses
const wallet = new Contract(ATLAS, FuseboxWallet, agentKey)

// dry run: would any fuse blow?
const [allowed, status] = await wallet.check(USDT0, to, amount)

// the real thing: every fuse runs on X Layer, in this call
await wallet.pay(USDT0, to, amount, "Invoice INV-7790")

// a stranger payee? Payee Guard says no, the Breaker latches,
// nothing moves, and the four designers earn 0.0045 USDT0
